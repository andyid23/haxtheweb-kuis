Tutorial Membuat Materi, Aktivitas, dan Kuis

Gunakan tutorial ini untuk membuat satu pertemuan, merekam aktivitas siswa, menyimpan hasil kuis, dan membaca rekap.

1. Siapkan Apps Script

  1. Buka Google Spreadsheet yang dipakai aplikasi.
  2. Buka Extensions → Apps Script.
  3. Tempel kode dari lib/code.gs, simpan, lalu jalankan fungsi pengujian bila diperlukan.
  4. Deploy sebagai Web app dengan Execute as: Me dan akses Anyone.
  5. Salin URL yang berakhiran /exec.
  6. Setelah mengubah Apps Script, selalu buat New version pada deployment.

2. Buat materi dan pertemuan

Pasang elemen dashboard dengan nama pertemuan yang diinginkan:

<quiz-dashboard-lite2
  apps-script-url="https://script.google.com/macros/s/DEPLOYMENT_ID/exec"
  sheet-name="Pertemuan 2">
</quiz-dashboard-lite2>

Nama tersebut membuat sheet hasil Pertemuan 2 - Kuis dan Pertemuan 2 - Aktivitas.

3. Buat aktivitas materi

Gunakan tipe aktivitas berikut pada materi:

  • reading — siswa membaca materi/scroll.
  • quiz — aktivitas soal atau evaluasi singkat.
  • discussion — diskusi atau forum.
  • download — mengunduh bahan.

Setiap aktivitas dikirim dengan data seperti:

{
  "type": "attendance",
  "activityType": "reading",
  "description": "Membaca materi pelajaran",
  "name": "Nama Siswa",
  "studentId": "STD-12345678",
  "nis": "12345",
  "sheet": "Pertemuan 2"
}

Pastikan siswa sudah login agar studentId, NIS, absen, kelas, dan nama otomatis ikut terkirim.

4. Lihat hasil

  • Pertemuan 2 - Aktivitas: detail waktu, siswa, tipe aktivitas, dan deskripsi.
  • Pertemuan 2 - Kuis: detail skor dan metadata siswa.
  • Rangkuman: total kuis, skor, total aktivitas, reading, quiz activity, discussion, download, dan jumlah pertemuan.
Jika data baru belum muncul, pastikan URL deployment sudah diperbarui dan jalankan ulang aksi setelah deployment baru aktif. Data lama yang hanya memiliki nama tidak dapat dikaitkan ke Student ID secara otomatis.

5. Pemeriksaan cepat

  1. Login memakai kombinasi NIS + email.
  2. Buka materi pada Pertemuan 2.
  3. Lakukan reading, discussion, atau download.
  4. Kerjakan kuis.
  5. Periksa tiga sheet di atas.
  6. Pastikan baris baru memiliki Student ID dan NIS.

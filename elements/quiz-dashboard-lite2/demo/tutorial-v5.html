Fix 1: Gradebook default

Dashboard sekarang selalu pass show-after-quiz ke transparent-gradebook, jadi perilaku tunggu kuis jalan tanpa setup tambahan.

<transparent-gradebook
  .appsScriptUrl="${this.appsScriptUrl}"
  .studentId="${this._user?.studentId || ''}"
  .studentName="${this._user?.nama || ''}"
  .viewMode="${this.viewMode}"
  .showAfterQuiz="${true}">
</transparent-gradebook>

Fix 2: Tab order

Urutan tab dipertahankan walau kuis disembunyikan: Panduan → Kuis → Aktivitas → Nilai.

<div class="tab-container">
  <button>Panduan</button>
  <button>Kuis</button>
  <button>Aktivitas</button>
  <button>Nilai</button>
</div>

Fix 3: Question text styling

`lib/explode-quiz.js` sekarang pakai DDD tokens dulu, lalu fallback hardcoded kalau token belum ada.

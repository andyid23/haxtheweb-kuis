BARU Reset Bobot Default

Tombol "🔄 Reset ke Default (1:3:2:2 = 8)" di mode dosen mengembalikan bobot ke standar.

File: attendance-system.js

Ditambahkan: method _resetWeights() + tombol di lecturer panel.

// attendance-system.js — _resetWeights()
_resetWeights() {
  const defaults = { ...DEFAULT_GRADES };
  localStorage.setItem(GRADES_STORAGE_KEY, JSON.stringify(defaults));
  this._gradesConfig = defaults;
  window.dispatchEvent(new CustomEvent("a3-force-reload"));
}

Tombol di render:

<button class="toggle-btn" @click="${() => this._resetWeights()}">
  🔄 Reset ke Default (1:3:2:2 = 8)
</button>

DEFAULT_GRADES (tidak berubah)

File: code.gs

// generateReport(weights) — dynamic weights dari client
function generateReport(weights) {
  const wAtt = (weights && parseInt(weights.attendanceWeight)) || 1;
  const wUH = (weights && parseInt(weights.ulanganHarianWeight)) || 3;
  const wUts = (weights && parseInt(weights.utsWeight)) || 2;
  const wUas = (weights && parseInt(weights.uasWeight)) || 2;
  const tw = wAtt + wUH + wUts + wUas;
  // formula: (kehadiran * wAtt/tw) + (uh * wUH/tw) + ...
}

Contoh: Kehadiran 50%, UH 50%, UTS 0%, UAS 0% → set attendanceWeight:1, ulanganHarianWeight:1, utsWeight:0, uasWeight:0 → tw=2 → formula benar.

FITUR Multi-Correct Checkbox UI

Soal dengan correctAnswers: [0, 2] (array) → render checkbox-style buttons + tombol "Kirim Jawaban".

File: explode-quiz.js

// _renderMC() — deteksi multi
const isMulti = Array.isArray(q.correctAnswers);
// render checkboxes + "Kirim Jawaban" button

// _submitMultiAnswers() — score = 1 jika SEMUA benar
_submitMultiAnswers() {
  const correct = new Set(q.correctAnswers || []);
  const selected = this._selectedAnswers;
  const isCorrect = correct.size === selected.size &&
    [...correct].every(c => selected.has(c));
  if (isCorrect) this._score += 1;
}
// Contoh soal multi-correct:
{
  "question": "Manakah framework CSS?",
  "choices": ["React", "Tailwind CSS", "Vue.js", "Bootstrap"],
  "correctAnswers": [1, 3]
}

_fetchRoster() {
  const url = `${this.appsScriptUrl}?action=getStudentRoster`;
  fetch(url).then(r => r.json()).then(data => {
    if (data.status === "ok") this._roster = data.roster;
  });
}

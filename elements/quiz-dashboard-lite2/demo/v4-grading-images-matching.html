📚 Dokumentasi v4 — Bug Fix & New Features

Fix 1: TransparentGradebook show-after-quiz

Root cause: Gradebook tidak punya listener untuk event quiz-saved di connectedCallback, sehingga _quizCompleted tetap false.

// attendance-system.js
connectedCallback() {
  super.connectedCallback();
  this._quizCompleteHandler = () => { this._quizCompleted = true; };
  window.addEventListener("quiz-saved", this._quizCompleteHandler);
  // ...
}
disconnectedCallback() {
  window.removeEventListener("quiz-saved", this._quizCompleteHandler);
  // ...
}

Penggunaan:

<quiz-dashboard-lite2 view-mode="student" ...></quiz-dashboard-lite2>
<!-- Gradebook ada di dalam dashboard, show-after-quiz control internal -->

Feature: Per-Choice Image URL

Backward compatible: string lama = text saja. Object baru = text + image.

// Format data:
{
  "choices": [
    {"text": "JavaScript", "image": "https://.../js.png"},
    "Python",  // string = text saja
    {"text": "Java", "image": "https://.../java.png"}
  ]
}

// Helper:
_getChoiceText(choice) {
  return typeof choice === 'string' ? choice : (choice?.text || '');
}
_getChoiceImage(choice) {
  return typeof choice === 'string' ? null : (choice?.image || null);
}

Feature: Matching Partial Score

_submitMatching() {
  let correctCount = 0;
  for (let i = 0; i < left.length; i++) {
    if (this._matchAnswers[i] === correctPairs[i]) correctCount++;
  }
  const earned = Math.round((correctCount / left.length) * (q.points || 1));
  this._score += earned;
  // Confetti hanya jika SEMUA benar
  if (!this.hideConfetti && correctCount === left.length) this._fireConfetti();
}

Contoh: 4 pasangan, points=4. Siswa jawab 2 benar → earned = round(2/4 × 4) = 2 poin. Feedback: "2/4 pasangan benar (+2 poin). Lanjutkan!"

📋 Penjelasan viewMode

viewMode Tampil
"student"Lihat transparansi nilai sendiri saja (read-only). Tombol ⚙️ Mode Dosen TIDAK tampil.
"lecturer"+ Tombol ⚙️ Mode Dosen tampil untuk akses konfigurasi bobot, generate rapor, input nilai manual UTS/UAS.

⚠️ Jangan tulis view-mode dua kali pada element yang sama! Atribut kedua menimpa yang pertama. Contoh salah:

<!-- ❌ SALAH — "lecturer" menimpa "student" -->
<quiz-dashboard-lite2 view-mode="student" view-mode="lecturer">

<!-- ✅ BENAR — pilih satu -->
<quiz-dashboard-lite2 view-mode="student">

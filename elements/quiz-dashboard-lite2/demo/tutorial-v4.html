Fix 1: TransparentGradebook show-after-quiz

Root cause: TransparentGradebook tidak punya listener untuk event quiz-saved di connectedCallback. Listener hanya ada di ActivityLogger. Jadi _quizCompleted tetap false selamanya.

Fix

// attendance-system.js — TransparentGradebook
connectedCallback() {
  super.connectedCallback();
  this._reloadHandler = () => { /* ... */ };
  this._quizCompleteHandler = () => { this._quizCompleted = true; };
  window.addEventListener("a3-activity-logged", this._reloadHandler);
  window.addEventListener("a3-force-reload", this._reloadHandler);
  window.addEventListener("quiz-saved", this._quizCompleteHandler);  // ← BARU
  this._fetchScores();
  this._fetchRoster();
}

disconnectedCallback() {
  window.removeEventListener("a3-activity-logged", this._reloadHandler);
  window.removeEventListener("a3-force-reload", this._reloadHandler);
  window.removeEventListener("quiz-saved", this._quizCompleteHandler);  // ← BARU
  super.disconnectedCallback();
}

Logika _shouldShowGradebook()

_shouldShowGradebook() {
  if (!this.showAfterQuiz && !this.showAfterDate) return true;
  if (this.showAfterQuiz && !this._quizCompleted) return false;
  if (this.showAfterDate && new Date() < new Date(this.showAfterDate)) return false;
  return true;
}

Penggunaan

<quiz-dashboard-lite2 view-mode="student" ...>
  <!-- gradebook ada di dalam dashboard, dikontrol via -->
  <transparent-gradebook
    show-after-quiz
    show-after-date="2026-08-15T00:00:00">
  </transparent-gradebook>
</quiz-dashboard-lite2>

Fix 2: gradebook-hidden Removed

Masalah: Saat gradebook-hidden=true, element <transparent-gradebook> tidak di-render ke DOM. Element tidak ada → tidak bisa listen event → tidak bisa show.

Fix

// quiz-dashboard-lite2.js
// Property gradebookHidden DIHAPUS
// Constructor: this.gradebookHidden = false; DIHAPUS

// Render — SELALU render gradebook
<transparent-gradebook
  .appsScriptUrl="${this.appsScriptUrl}"
  .studentId="${this._user?.studentId || ''}"
  .studentName="${this._user?.nama || ''}"
  .viewMode="${this.viewMode}">
</transparent-gradebook>

Sekarang gradebook selalu ada di DOM, dengan logic internal:

  • Default: langsung tampil
  • show-after-quiz: tunggu quiz-saved event
  • show-after-date: tunggu sampai tanggal tertentu

Fix 3: Edit Button dari Question Screen

Masalah: _openEditor() hanya izinkan dari "result" screen. Tombol edit hanya muncul di result screen. User tidak bisa edit dari question screen.

Fix

// _openEditor() — izinkan dari result ATAU question
_openEditor() {
  if (this._editing) return;
  if (this._screen !== "result" && this._screen !== "question") return;
  this._editing = true;
  this._editingIndex = -1;
  this._tempQuestions = JSON.parse(JSON.stringify(this.questions));
  this._screen = "editor";
}

Tombol Edit di Question Screen

// _renderQuestionScreen() — tambah di bawah feedback
${this.editable ? html`

    style="margin-top:12px;font-size:12px;padding:6px 12px;"
    @click="${this._openEditor}">
    ✏️ Edit Soal
  </button>
` : ""}

Feature: Per-Choice Image URL

Setiap pilihan jawaban sekarang bisa punya URL gambar sendiri. Backward compatible dengan format lama (string).

Format Data

{
  "type": "mc",
  "question": "Logo mana yang untuk web development?",
  "choices": [
    { "text": "JavaScript", "image": "https://.../js.png" },
    "Python",
    { "text": "Java", "image": "https://.../java.png" },
    "C++"
  ],
  "correctIndex": 0
}

Helper Methods

_getChoiceText(choice) {
  return typeof choice === 'string' ? choice : (choice?.text || '');
}
_getChoiceImage(choice) {
  return typeof choice === 'string' ? null : (choice?.image || null);
}

Editor Fields

Di editor HAXcms / edit mode, setiap pilihan sekarang punya:

  • Input text pilihan (seperti sebelumnya)
  • Input URL gambar (baru)
  • Checkbox "Benar"
  • Preview thumbnail (jika URL diisi)

Display

Feature: Matching Partial Score

Sebelum: Semua-atau-tidak. 1 salah = 0 poin.

Sekarang: Skor proporsional. 4 pasangan points=4, siswa jawab 2 benar → 2 poin.

_submitMatching() {
  let correctCount = 0;
  for (let i = 0; i < left.length; i++) {
    if (this._matchAnswers[i] === correctPairs[i]) correctCount++;
  }
  const earned = Math.round((correctCount / left.length) * (q.points || 1));
  this._score += earned;
  
  if (!this.hideConfetti && correctCount === left.length) {
    this._fireConfetti();
  }
}

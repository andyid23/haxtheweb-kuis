BUG FIX Delete Komentar + Anak Reply

Masalah

Ketika menghapus komentar induk di sheet, reply/anak komentar tidak ikut terhapus. Contoh:

Timestamp              | CommentID     | ParentID      | UserName
26/07/2026 15:17:37    | 1785053854286 | 1785050828652 | andy  ← reply (ParentID = induk)
26/07/2026 15:43:38    | 1785055415814 | 1785050828652 | andy  ← reply (ParentID = induk)
26/07/2026 18:26:29    | 1785065186782 | main          | Andy  ← induk (ID = 1785065186782)

Fix

code-forum-tugas.gs + code.gs:

// deleteForumComment — hapus parent + semua reply
const rowsToDelete = [];
for (let i = allData.length - 1; i >= 1; i--) {
  if (String(allData[i][1]) === commentId || String(allData[i][2]) === commentId) {
    rowsToDelete.push(i + 1); // ParentID match = reply juga dihapus
  }
}
rowsToDelete.forEach(row => sheet.deleteRow(row));

assignment-forum.js — frontend juga hapus children:

// _deleteComment() — collect parent + children IDs
const idsToDelete = new Set([commentId]);
this._comments.forEach(c => {
  if (c.id === commentId && c.replies) {
    c.replies.forEach(r => idsToDelete.add(r.id));
  }
});
this._comments = this._comments.filter(c => !idsToDelete.has(c.id));

BUG FIX Vote Button pada Reply Card

Masalah

Tombol 🔺 dan 🔻 pada reply card tidak berfungsi. Klik vote tidak ada efek.

Root Cause

_handleLike() hanya search this._comments (top-level). Reply ada di c.replies (nested).

Fix

// Helper recursive — cari comment di mana saja (parent atau child)
_findAndUpdateComment(comments, id, updater) {
  return comments.map(c => {
    if (c.id === id) return updater(c);
    if (c.replies && c.replies.length > 0) {
      return { ...c, replies: this._findAndUpdateComment(c.replies, id, updater) };
    }
    return c;
  });
}

// _handleLike & _handleDislike sekarang pakai helper ini
this._comments = this._findAndUpdateComment(this._comments, commentId, c => {
  const isLiked = !c.isLiked;
  return { ...c, isLiked, likes: isLiked ? (c.likes || 0) + 1 : (c.likes || 0) - 1 };
});

BARU Validasi Link Google Drive/Docs

Input link divalidasi sebelum submit. URL harus valid (http/https).

_isValidUrl(str) {
  try { const u = new URL(str); return u.protocol === "http:" || u.protocol === "https:"; }
  catch { return false; }
}

// Di _submitAssignment():
if (this._assignmentLink && !this._isValidUrl(this._assignmentLink)) {
  alert("Format link tidak valid. Gunakan URL Google Drive/Doc.");
  return;
}

Tugas juga bisa dikirim tanpa link (hanya text) atau tanpa text (hanya link).

BARU show-after-quiz + show-after-date

Properties di <transparent-gradebook> untuk kontrol kapan gradebook muncul.

<transparent-gradebook
  show-after-quiz
  show-after-date="2026-08-15T00:00:00"
  ...>
</transparent-gradebook>
PropertyAttributeEffect
showAfterQuizshow-after-quizMuncul hanya setelah siswa menyelesaikan kuis
showAfterDateshow-after-dateMuncul setelah tanggal/waktu tertentu (ISO format)

Logika

_shouldShowGradebook() {
  if (!this.showAfterQuiz && !this.showAfterDate) return true; // always show
  if (this.showAfterQuiz && !this._quizCompleted) return false;
  if (this.showAfterDate && new Date() < new Date(this.showAfterDate)) return false;
  return true;
}

Ketika tidak muncul, tampilkan pesan: "Transparansi nilai akan muncul setelah kuis diselesaikan atau pada waktu yang ditentukan."

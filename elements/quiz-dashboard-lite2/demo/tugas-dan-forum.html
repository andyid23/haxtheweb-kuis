📝 Tugas Mandiri & Forum Diskusi

Syarat Kehadiran Minimum: Minimal 1 pertemuan per minggu = mengerjakan tugas mandiri + aktif forum.

Fitur:
• <assignment-forum> — elemen web Lit baru
• Tugas mandiri terkunci setelah dikirim (bisa reset)
• Forum diskusi real-time dengan localStorage
• Otomatis trigger assignment-saved & discussion-saved event
• Integritas dengan activity-logger untuk tracking kehadiran
• Export tugas ke file .txt

🔧 Cara Pakai

<assignment-forum
  assignment-title="Judul Tugas"
  assignment-instruction="Instruksi tugas..."
  forum-topik="Topik Forum"
  apps-script-url="https://script.google.com/macros/s/AKfycbw6iaBn4NYNwmN9z-Bks4P302cXlxiGiz4Uxr7gUyoR5y62JLEOagV3S5uhV_J7e8-V/exec"
  sheet-name="Pertemuan 1">
</assignment-forum>

Integrasi dengan Dashboard

// Di quiz-dashboard-lite2.js, tambahkan import:
import "./lib/assignment-forum.js";

// Di template, di tab Kehadiran:
<assignment-forum
  .appsScriptUrl="${this.appsScriptUrl}"
  .sheetName="${this.sheetName}"
  .studentId="${this._user?.studentId}"
  .studentName="${this._user?.nama}"
  assignment-title="Tugas Pertemuan 5"
  forum-topik="Diskusi Materi Pertemuan 5">
</assignment-forum>

Syarat Kehadiran (Logic)

Siswa dianggap hadir jika dalam 1 minggu melakukan minimal 1 tugas mandiri DAN minimal 1 postingan forum. Event assignment-saved dan discussion-saved otomatis tercatat ke Google Sheets via activity-logger. 

// Threshold kehadiran di attendance-system.js:
minWeeklyActivities: 10  // total aktivitas/minggu
minAssignment: 1         // minimal 1 tugas
minDiscussion: 1         // minimal 1 forum
minReading: 5            // minimal 5 baca
minQuiz: 1               // minimal 1 kuis formatif

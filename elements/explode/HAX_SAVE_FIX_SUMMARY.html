Ringkasan Fix: dan HAX Save

Dokumen ini merangkum akar masalah, perubahan teknis, dampak warning, dan panduan pengembangan komponen ke depan.

Status saat ini

Save sudah berhasil — atribut questions tersimpan ke HTML dan dapat direstore saat reload.

Warning Import already in progress, skipping duplicate call masih bisa muncul, namun pada hasil akhir bersifat non-fatal (tidak memblok save).

1) Akar Masalah Awal

  • Properti questions bertipe Array sebelumnya tidak aman untuk proses serialisasi HAX ke HTML.
  • HAX menyimpan konten sebagai atribut DOM; jika nilai tidak konsisten/invalid, data tidak tersimpan atau runtime jadi tidak stabil.
  • Jalur UI editor berbasis code-editor/monaco pada konfigurasi questions ikut memicu potensi hang/race pada mode edit tertentu.

2) Perubahan yang Diterapkan

Persistensi atribut questions

  • questions di-set reflect: true
  • Converter custom:
    • toAttribute serialize JSON
    • fromAttribute parse JSON dengan fallback aman
  • Menangani nilai buruk: undefined, null, [object Object], parse error

Hardening HAX metadata

  • Tambahkan settings.developer: []
  • Tambahkan saveOptions.unsetAttributes untuk state internal
  • Mencegah state transient ikut tersimpan ke HTML saat save

Isolasi jalur rawan hang

  • Field questions di settings.configure dihapus sementara.
  • Editing soal diarahkan lewat editor internal komponen (Edit Soal Kuis), lalu persisted ke atribut questions.

3) Makna Warning HAX

Warning 
hax-body.js:445 Import already in progress, skipping duplicate call
  • Ini guard di pipeline import HAX untuk mencegah import ganda saat ada request overlap/race.
  • Efek: panggilan duplikat diabaikan. Biasanya tidak fatal bila state akhir tetap konsisten.
  • Pada hasil saat ini: save tetap berjalan, jadi warning ini bukan blocker utama.

4) Dampak ke Pengguna Authoring

  • Author dapat save konten tanpa kehilangan data soal.
  • questions tersimpan di tag HTML dan kembali saat reload.
  • Konfigurasi soal lewat panel HAX untuk field JSON sementara tidak dipakai (pakai editor internal komponen).

5) Panduan Pengembangan ke Depan

Prinsip desain komponen HAX-friendly

  • Semua data penting harus bisa round-trip lewat atribut HTML.
  • Pisahkan state persisten vs state UI sementara.
  • Gunakan unsetAttributes untuk state sementara/editor.
  • Converter wajib defensif untuk input invalid.

Strategi UI konfigurasi

  • Hindari field JSON kompleks di code-editor jika pipeline belum stabil.
  • Prioritaskan editor internal komponen untuk struktur data kompleks.
  • Jika perlu panel HAX, gunakan format sederhana + validasi ketat.

6) Checklist Regression yang Direkomendasikan

  • Edit mode ON → ubah quiz → save → reload (ulang 2–3 kali)
  • Pastikan atribut questions='[...]' tetap valid JSON
  • Uji flow quiz penuh: name → question → result
  • Uji halaman lain di HAX editor agar warning import tidak berdampak lintas halaman

7) Contoh Snippet Konsep Aman

// contoh konsep (ringkas)
questions: {
  type: Array,
  attribute: "questions",
  reflect: true,
  converter: {
    fromAttribute(value) { /* parse defensif */ },
    toAttribute(value) { /* JSON.stringify aman */ }
  }
},
saveOptions: {
  unsetAttributes: ["_screen", "_tempQuestions", "_editingIndex", "..."]
}

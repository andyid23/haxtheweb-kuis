🎯 Apa itu Sistem Attendance?

Sistem attendance adalah cara otomatis untuk mencatat kehadiran mahasiswa berdasarkan aktivitas pembelajaran mereka, bukan tanda tangan manual.

💡 Konsep Utama: Kehadiran = Aktivitas Belajar yang Terdeteksi Otomatis oleh Sistem

Tampilkan Statistik

1. Event Listeners (Deteksi Otomatis)

Sistem mendeteksi 3 jenis interaksi pengguna:

Event Trigger Tipe Aktivitas Throttle
scroll User scroll > 300px reading 1x per 60 detik
click Klik link/button reading/download Setiap klik valid
quiz-saved Kuis selesai quiz Setiap kuis selesai

2. Penyimpanan Data

Semua aktivitas tersimpan di localStorage browser dengan format:

// Key di localStorage
"a3_attendance_activity_logs"

// Format data (JSON array)
[
  {
    "id": "log-1721234567890-0.123",
    "timestamp": "2026-07-22T10:30:00.000Z",
    "type": "reading",
    "description": "Membaca materi pelajaran (Scroll ke baris 450px)"
  },
  {
    "id": "log-1721234567891-0.456",
    "timestamp": "2026-07-22T10:35:00.000Z",
    "type": "quiz",
    "description": "Menyelesaikan Kuis Interaktif (Skor diperoleh: 80%)"
  }
]

3. Perhitungan Kehadiran

Kehadiran dihitung dari 4 kriteria dalam 7 hari terakhir:

Kriteria Minimal Icon Cara Terpenuhi
📖 Membaca Modul 2x ✅ Scroll materi atau klik link
📝 Kuis Selesai 1x ✅ Mengerjakan kuis apapun
💬 Forum & Diskusi 1x ✅ Klik tombol diskusi/forum
📈 Total Aktivitas 5x ✅ Semua jenis aktivitas digabung
✅ Rumus Kehadiran: Kehadiran = (Jumlah Kriteria Terpenuhi / 4) × 100%
Contoh: 3 dari 4 kriteria terpenuhi = 75% = HADIR

🧩 Komponen Web yang Tersedia

📊 <activity-logger>

Fungsi: Mencatat semua aktivitas pengguna secara otomatis

  • Deteksi scroll (throttle 60 detik)
  • Deteksi klik link download
  • Deteksi kuis selesai (event quiz-saved)
  • Menampilkan toast notification
  • Floating pill di pojok kanan bawah
  • Simulator untuk testing
Aktivitas Terrekam (42)

📅 <attendance-tracker>

Fungsi: Menampilkan status kehadiran mingguan

  • Gauge chart persentase kehadiran
  • Checklist 4 kriteria kehadiran
  • Progress bar per kriteria
  • Auto-update saat aktivitas baru tercatat
75%

🔥 <engagement-score>

Fungsi: Menampilkan heatmap aktivitas dan streak belajar

  • Heatmap grid 28 hari (seperti GitHub)
  • 5 level warna berdasarkan jumlah aktivitas
  • Klik cell untuk lihat detail hari
  • Streak counter (hari berturut-turut aktif)
  • Consistency index (persentase hari aktif)

📖 <transparent-gradebook>

Fungsi: Menghitung dan menampilkan nilai akhir transparan

  • Summary bento grid (kehadiran, kuis, UTS, UAS, grade)
  • Tabel rinci setiap komponen nilai
  • Mode Dosen (input UTS/UAS, ubah bobot)
  • Roster simulasi anggota kelas
  • Bobot bisa dikustomisasi

💾 Penyimpanan Data

⚠️ Penting: Saat ini, data attendance HANYA tersimpan di localStorage browser (lokal). Data TIDAK otomatis terkirim ke Google Sheets.

Data yang Disimpan di localStorage

Key Isi Keterangan
a3_attendance_activity_logs Array log aktivitas Semua aktivitas tercatat
a3_attendance_threshold_config Object threshold Minimal aktivitas per kriteria
a3_attendance_grades_config Object bobot nilai Bobot kehadiran, kuis, UTS, UAS
apps_script_url URL string URL Google Apps Script (untuk kuis)
quiz_lite_sheet_id ID string ID Google Spreadsheet (untuk kuis)

🔧 Cara Memasukkan Elemen Web

Metode 1: Langsung di HTML (Untuk Demo/Standalone)

Cukup tambahkan tag custom element di HTML:

<script type="module" src="attendance-system.js"></script>

<!-- Gunakan elemen -->
<activity-logger></activity-logger>
<attendance-tracker></attendance-tracker>
<engagement-score></engagement-score>
<transparent-gradebook></transparent-gradebook>

Metode 2: Di HAXcms Editor

  1. Buka editor HAXcms
  2. Klik tombol "Tambah Elemen (+)" di panel kiri
  3. Cari kata kunci: "Activity Logger", "Attendance Tracker", dll
  4. Klik atau seret elemen ke halaman

Metode 3: Manual Tag di HAXcms (Source Mode)

  1. Di editor HAXcms, klik tombol "Source" atau "HTML"
  2. Paste tag berikut:
<activity-logger></activity-logger>

<attendance-tracker></attendance-tracker>

🚀 Quick Reference

Cara Cek Data di Console Browser

// Buka Console (F12) dan jalankan:

// 1. Lihat semua log aktivitas
JSON.parse(localStorage.getItem("a3_attendance_activity_logs"))

// 2. Hitung total aktivitas per tipe
const logs = JSON.parse(localStorage.getItem("a3_attendance_activity_logs"));
const counts = {
  reading: logs.filter(l => l.type === "reading").length,
  quiz: logs.filter(l => l.type === "quiz").length,
  discussion: logs.filter(l => l.type === "discussion").length,
  download: logs.filter(l => l.type === "download").length
};
console.log("Statistik:", counts);

// 3. Reset semua data (hati-hati!)
localStorage.removeItem("a3_attendance_activity_logs");
location.reload();

Cara Simulate Aktivitas (untuk Testing)

// Di Console browser:

// Simulate reading activity
localStorage.setItem("a3_attendance_activity_logs", JSON.stringify([
  {
    id: "test-1",
    timestamp: new Date().toISOString(),
    type: "reading",
    description: "Test reading activity"
  }
]));
location.reload();

Cara Export Data (Backup)

// Copy data ke clipboard
copy(JSON.stringify(JSON.parse(localStorage.getItem("a3_attendance_activity_logs")), null, 2));

// Paste ke text editor dan simpan sebagai .json

❓ FAQ

Q: Apakah data attendance otomatis terkirim ke Google Sheets?

A: Tidak. Saat ini data hanya tersimpan di localStorage browser. Hanya data kuis yang terkirim ke Google Sheets via Apps Script.

Q: Bagaimana cara dosen melihat data attendance mahasiswa?

A: Saat ini belum bisa otomatis. Dosen harus meminta mahasiswa export data mereka secara manual, atau perlu dibuatkan integrasi khusus untuk mengirim data attendance ke Sheets.

Q: Apakah data hilang jika ganti browser?

A: Ya. Data localStorage bersifat per-browser. Jika ganti browser atau clear cache, data hilang. Solusi: export data secara berkala.

Q: Bagaimana cara reset data attendance?

A: Buka Console (F12) dan jalankan:

localStorage.removeItem("a3_attendance_activity_logs");
location.reload();

Q: Bisa attendance dikirim ke Google Sheets juga?

A: Bisa, tapi perlu modifikasi kode. Tambahkan fungsi untuk mengirim data attendance ke Apps Script setiap kali aktivitas baru tercatat. Ini memerlukan perubahan pada attendance-system.js.

Q: Apakah scroll dihitung terus-menerus?

A: Tidak. Ada throttle 60 detik. Hanya 1 log per menit saat scroll aktif.

Q: Bagaimana cara menambah tipe aktivitas baru?

A: Edit fungsi _handleClick() atau _handleScroll() di attendance-system.js untuk mendeteksi event baru.

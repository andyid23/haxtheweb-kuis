📖 Tutorial Lengkap: Setup Google Apps Script

Panduan langkah demi langkah untuk menghubungkan kuis dengan Google Sheets

🎯 Apa yang Akan Kita Buat?

Tutorial ini akan membantu Anda membuat sistem kuis yang dapat menyimpan hasil secara otomatis ke Google Sheets tanpa perlu server backend atau Firebase. Kita akan menggunakan Google Apps Script sebagai jembatan.

✅ Kelebihan

Tidak perlu server, Firebase, atau backend. Gratis dan mudah di-setup. Data langsung tersimpan di Google Drive Anda.

⚠️ Keterbatasan

Hanya bisa menyimpan data (POST). Untuk membaca data leaderboard, perlu akses manual ke Sheets atau Firebase.

📋 Persiapan yang Dibutuhkan

  • Akun Google (Gmail)
  • Browser web (Chrome, Firefox, Edge, dll)
  • File demo standalone.html yang sudah dibuat
  • 5-10 menit waktu untuk setup

🚀 Langkah 1: Buat Google Spreadsheet

  1. Buka Google Sheets
  2. Klik "Blank" atau "Untitled spreadsheet" untuk buat baru
  3. Beri nama spreadsheet: "Hasil Kuis Interaktif"
  4. Copy ID dari URL spreadsheet Anda

📱 Screenshot: Google Sheets dengan URL yang menunjukkan ID

URL format: https://docs.google.com/spreadsheets/d/[ID_DISINI]/edit

💡 Tips: ID spreadsheet adalah string acak di URL, contoh: 1BxiMVs0XRA5nFMdKvBdBZjgmUUqptlbs74OgVE2upms

🚀 Langkah 2: Buka Google Apps Script

  1. Di Google Sheets yang baru dibuat, klik menu Extensions → Apps Script
  2. Akan terbuka tab baru dengan editor Apps Script
  3. Hapus semua kode default yang ada di editor

🚀 Langkah 3: Copy-Paste Kode Apps Script

Copy seluruh kode di bawah ini dan paste ke editor Apps Script:

/**
 * Google Apps Script untuk Menerima Hasil Kuis
 * Deploy sebagai Web App untuk menerima data dari browser
 */

const SHEET_NAME = "Hasil Kuis";

// Handler untuk GET request (health check)
function doGet(e) {
  return ContentService.createTextOutput(JSON.stringify({
    status: "ok",
    message: "Quiz API is running"
  })).setMimeType(ContentService.MimeType.JSON);
}

// Handler untuk POST request (terima hasil kuis)
function doPost(e) {
  try {
    let data;
    
    if (e.postData && e.postData.contents) {
      data = JSON.parse(e.postData.contents);
    } else {
      data = {
        name: e.parameter.name || "Unknown",
        score: e.parameter.score || 0,
        timestamp: e.parameter.timestamp || new Date().toISOString()
      };
    }
    
    if (!data.name || data.score === undefined) {
      return ContentService.createTextOutput(JSON.stringify({
        status: "error",
        message: "Missing name or score"
      })).setMimeType(ContentService.MimeType.JSON);
    }
    
    const result = saveToSheet(data);
    
    return ContentService.createTextOutput(JSON.stringify({
      status: "success",
      message: "Result saved",
      data: result
    })).setMimeType(ContentService.MimeType.JSON);
    
  } catch (error) {
    return ContentService.createTextOutput(JSON.stringify({
      status: "error",
      message: error.toString()
    })).setMimeType(ContentService.MimeType.JSON);
  }
}

// Fungsi untuk menyimpan ke sheet
function saveToSheet(data) {
  const spreadsheet = SpreadsheetApp.getActiveSpreadsheet();
  let sheet = spreadsheet.getSheetByName(SHEET_NAME);
  
  if (!sheet) {
    sheet = spreadsheet.insertSheet(SHEET_NAME);
    sheet.appendRow(["Timestamp", "Nama", "Skor (%)", "Total Soal", "Status"]);
    sheet.getRange(1, 1, 1, 5).setFontWeight("bold");
    sheet.getRange(1, 1, 1, 5).setBackground("#6750a4");
    sheet.getRange(1, 1, 1, 5).setFontColor("white");
  }
  
  const totalSoal = data.totalQuestions || 5;
  const status = data.score >= 70 ? "LULUS" : "TIDAK LULUS";
  const timestamp = data.timestamp ? new Date(data.timestamp) : new Date();
  const formattedTime = Utilities.formatDate(timestamp, "Asia/Jakarta", "dd/MM/yyyy HH:mm:ss");
  
  sheet.appendRow([formattedTime, data.name, data.score, totalSoal, status]);
  
  const lastRow = sheet.getLastRow();
  const range = sheet.getRange(lastRow, 1, 1, 5);
  range.setBackground(data.score >= 70 ? "#d1fae5" : "#fee2e2");
  
  return { row: lastRow, name: data.name, score: data.score, status: status };
}
⚠️ Perhatian: Pastikan Anda menyalin SELURUH kode, termasuk fungsi doGet, doPost, dan saveToSheet.

🚀 Langkah 4: Simpan dan Deploy

  1. Klik tombol "Save project" (ikon disket) atau tekan Ctrl+S
  2. Beri nama project: "Quiz Result Handler"
  3. Klik tombol "Deploy" di pojok kanan atas
  4. Pilih "New deployment"
  5. Klik ikon gear ⚙️ dan pilih "Web app"
  6. Isi konfigurasi:
    • Description: "Quiz Result API" (atau terserah Anda)
    • Execute as: "Me" (akun Anda)
    • Who has access: "Anyone" (agar bisa diakses dari browser manapun)
  7. Klik "Deploy"
  8. Akan muncul dialog otorisasi - klik "Authorize access"
  9. Pilih akun Google Anda
  10. Klik "Advanced" → "Go to Quiz Result Handler (unsafe)"
  11. Klik "Allow"

⚙️ Cara Kerja Sistem

1. Activity Logger (Pelacakan Aktivitas Otomatis)

Komponen <activity-logger> bekerja di latar belakang untuk mencatat:

  • Scroll: Setiap Anda scroll lebih dari 300px, aktivitas "Membaca materi" tercatat
  • Klik Link: Klik link download atau eksternal tercatat sebagai aktivitas
  • Kuis Selesai: Setelah menyelesaikan kuis, skor tercatat otomatis

Semua aktivitas tersimpan di localStorage browser dengan key a3_attendance_activity_logs.

2. Attendance Tracker (Pelacakan Kehadiran)

Kehadiran dihitung dari 4 kriteria dalam 7 hari terakhir:

Kriteria Minimal Keterangan
📖 Membaca Modul 2x Scroll dan klik materi
📝 Kuis Selesai 1x Menyelesaikan kuis apapun
💬 Forum & Diskusi 1x Klik tombol diskusi/forum
📈 Total Aktivitas 5x Semua jenis aktivitas digabung

3. Engagement Score (Skor Konsistensi)

Menampilkan heatmap aktivitas 28 hari terakhir. Semakin banyak aktivitas, semakin gelap warnanya. Juga menghitung streak (hari berturut-turut aktif).

4. Transparent Gradebook (Transparansi Nilai)

Menghitung nilai akhir berdasarkan komponen:

  • Kehadiran: 30% (dari Attendance Tracker)
  • Kuis: 20% (skor tertinggi dari kuis yang dikerjakan)
  • UTS: 25% (input manual dosen)
  • UAS: 25% (input manual dosen)

🔧 Troubleshooting (Masalah Umum)

❌ Error: "Gagal menyimpan ke Google Sheets"

Penyebab: URL Apps Script salah atau belum di-deploy sebagai Web App.
Solusi:
  • Pastikan URL diawali dengan https://script.google.com/macros/s/...
  • Pastikan deployment type adalah "Web app", bukan "API Executable"
  • Pastikan "Who has access" di-set ke "Anyone"

❌ Data tidak muncul di Google Sheets

Penyebab: Apps Script error saat menjalankan kode.
Solusi:
  • Buka Google Apps Script editor
  • Klik menu Executions di sidebar kiri
  • Check apakah ada error log
  • Pastikan kode di-copy dengan lengkap tanpa potong

❌ Error otorisasi saat deploy

Penyebab: Google menandai script sebagai "unsafe" karena belum diverifikasi.
Solusi:
  • Klik "Advanced" di dialog peringatan
  • Klik "Go to [nama project] (unsafe)"
  • Klik "Allow" untuk memberikan akses
  • Ini aman karena script ini milik Anda sendiri

❌ Kuis berfungsi tapi tidak tersimpan

Penyebab: Browser memblokir request CORS.
Solusi:
  • Apps Script menggunakan mode: 'no-cors' yang seharusnya mengatasi ini
  • Coba buka halaman langsung (bukan dari file://) - gunakan local server
  • Check Console browser (F12) untuk error spesifik

🚀 Advanced: Customisasi Lebih Lanjut

Ubah Threshold Kehadiran

Anda bisa mengubah minimal aktivitas yang dibutuhkan untuk dianggap "Hadir". Buka Console browser (F12) dan jalankan: 

// Ubah threshold kehadiran
localStorage.setItem('a3_attendance_threshold_config', JSON.stringify({
  minWeeklyActivities: 3,  // Default: 5
  minReading: 1,           // Default: 2
  minQuiz: 1,              // Default: 1
  minDiscussion: 1         // Default: 1
}));

Ubah Bobot Nilai

// Ubah bobot penilaian
localStorage.setItem('a3_attendance_grades_config', JSON.stringify({
  uts: 85,                // Nilai UTS (input manual)
  uas: 88,                // Nilai UAS (input manual)
  attendanceWeight: 30,   // Bobot kehadiran (%)
  quizWeight: 20,         // Bobot kuis (%)
  utsWeight: 25,          // Bobot UTS (%)
  uasWeight: 25           // Bobot UAS (%)
}));

Tambah Soal Kustom

Di tab "Ambil Kuis", scroll ke bawah dan klik tombol "Edit Soal Kuis" untuk menambah, edit, atau hapus soal. Soal kustom tersimpan otomatis di localStorage.

Reset Semua Data

// Reset semua data (hati-hati!)
localStorage.removeItem('a3_attendance_activity_logs');
localStorage.removeItem('a3_attendance_threshold_config');
localStorage.removeItem('a3_attendance_grades_config');
localStorage.removeItem('quiz_lite_sheet_id');

❓ FAQ (Pertanyaan yang Sering Diajukan)

Q: Apakah ini gratis?

A: Ya! Google Apps Script gratis untuk penggunaan normal. Batasnya adalah 20,000 eksekusi per hari.

Q: Apakah perlu install apapun?

A: Tidak! Semua berjalan di browser. Anda hanya perlu file HTML dan akun Google.

Q: Bisa digunakan untuk banyak siswa?

A: Ya! Setiap siswa tinggal buka file HTML yang sama. Semua data masuk ke satu Google Sheets.

Q: Apakah data bisa diakses oleh orang lain?

A: Data di Google Sheets hanya bisa diakses oleh Anda (pemilik). Apps Script hanya bisa menulis, tidak membaca.

Q: Bagaimana jika saya ingin membaca data juga (untuk leaderboard)?

A: Untuk fitur leaderboard, Anda perlu Firebase atau backend server. Apps Script hanya untuk menyimpan data.

Q: Bisa digunakan offline?

A: Kuis bisa dikerjakan offline, tapi hasil hanya tersimpan di browser. Data akan terkirim ke Sheets saat online kembali (jika Anda refresh halaman).

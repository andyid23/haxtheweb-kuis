🧪 Test Google Apps Script Connection

Halaman ini untuk menguji apakah Google Apps Script Anda sudah benar dikonfigurasi.

📋 Checklist Sebelum Test

  1. Apps Script sudah di-deploy sebagai Web App (bukan API Executable)
  2. Execute as: "Me" (akun Anda)
  3. Who has access: "Anyone"
  4. Kode Apps Script sudah di-copy lengkap (doGet, doPost, saveToSheet)
  5. Sudah klik "Authorize access" dan memberikan izin

🔍 Cara Membaca Hasil Test

  • ✅ Berhasil: Cek Google Sheets Anda. Jika ada baris baru dengan nama "TEST - ...", berarti BERHASIL!
  • ❌ Gagal: Buka Console browser (F12) dan cek error log
  • ⚠️ Tidak yakin: Karena mode no-cors, browser tidak bisa membaca response. Yang penting adalah data muncul di Google Sheets.

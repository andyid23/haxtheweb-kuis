3. Kuis di Halaman Lain Tetap Mencentang "Mengerjakan Kuis"

  • Saat kuis selesai, explode-quiz menulis log lokal quiz ke localStorage (key a3_attendance_logs) via helper pushLocalLog(), lalu memancarkan event a3-activity-logged.
  • Halaman dashboard yang sedang terbuka ter-refresh otomatis lewat event tersebut.
  • Tab/window lain pada asal yang sama (mis. halaman kuis & dashboard satu site) ter-refresh lewat event storage browser â€” kuis di halaman terpisah otomatis mencentang kriteria tanpa reload manual.
  • Setelah halaman dimuat ulang, data tetap terbaca dari localStorage; data server (sheet) tetap menjadi sumber akhir.

4. Heatmap Aktivitas (2 Kolom)

  • Komponen <engagement-score> kini menampilkan heatmap 1 bulan dengan grid 2 kolom: kiri heatmap (sel lebih besar), kanan ringkasan Total Aktivitas / Hari Aktif / Indeks Konsistensi + keterangan + legenda.
  • Di layar sempit (<768px) otomatis menjadi 1 kolom; di HP kecil sel mengecil agar tetap muat.
  • Sumber: getActivityHistory (sheet Aktivitas + pertemuan-kuis) dan getForumActivityHistory bila forum-api-url diisi.
